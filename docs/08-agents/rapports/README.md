# Rapports des agents

Sorties des agents en exploitation, au format `docs/08-agents/modeles/RAPPORT_AGENT.md`. Vide au 4.10.2026 : aucun agent n'a encore été exécuté en exploitation.

## Règles

| Règle | Détail |
|---|---|
| Nom de fichier | `AAAA-MM-JJ_<agent>_<sujet>.md` (ex. `2026-10-12_sourcing_relances-j5.md`) ; plan du jour : `AAAA-MM-JJ_chef-de-projet_dispatch.md` |
| Auteur | L'agent lui-même s'il a l'outil Write ; sinon (`qa-conformite`) le chef de projet archive le rapport rendu |
| Contenu interdit | Secret, identifiant, IBAN, document d'identité ; nom, adresse, email ou téléphone d'un client (numéro de commande seulement) |
| Contenu autorisé | Coûts internes et marges (le dépôt est privé) ; jamais copiés vers une sortie publique |
| Modification | Un rapport publié n'est pas réécrit : un correctif = un nouveau rapport qui cite l'ancien |
| Conservation | Durée à fixer par la propriétaire (pièces comptables : selon l'avis de la fiduciaire) |

## Validation humaine requise

- [ ] Fixer la durée de conservation des rapports et confirmer qu'ils peuvent rester dans le dépôt privé.
